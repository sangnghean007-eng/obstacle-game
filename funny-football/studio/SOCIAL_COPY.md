# Social copy guide: how we write posts (YouTube · TikTok · Instagram · Facebook · X)

Use this guide for every release dossier (`toon2/epN/release/*.md`). It was researched on Nov 14, 2026.
- Most sources are marketing blogs, not official platform docs. Rules marked **(consensus)** are agreed by several sources; rules marked **(unsure)** are where sources disagree. Re-check those every few months.
- Real numbers in `performance.csv` beat this guide. When our data disagrees, update this file.

## 0. House rules for all platforms
- **Language:** all copy in English (simple words; a Vietnamese 18-year-old must get it).
- **Facts:** every fact in a caption is in `facts.md` with 2+ sources. Write "parody" next to anything invented. No quotes unless they are VERBATIM and sourced. Real coaches stay unnamed.
- **The first line is everything.** All platforms cut the caption after the first line or so. The first line = **hook + main keyword** (the player/team name a fan would search, e.g. "Ronaldo", "Portugal 1-4 Denmark"). **(consensus)**
- **Keywords in plain words beat hashtags** for search on TikTok, Instagram and YouTube. Write the names out in the sentence; hashtags are a bonus. **(consensus)**
- **One question per post.** Use a binary or numbered question (YES 7 / NO, "comment 1–4"). Never stack 3 CTAs.
- **The pinned comment asks a different question** from the caption, so there are two ways in.
- **Match the video:** the caption hook should repeat the on-screen hook text (same words → stronger relevance signal). **(consensus, TikTok/IG)**
- **Footer line on every platform:** "Real results/stats (date) · cartoon parody, original characters."
- **No @-mentions** of players, clubs or federations; no logos; no "official" wording.
- **Reply to every comment in the first hour.** Replies count as comments, and early engagement drives distribution on all 5 platforms. **(consensus)**

## 1. YouTube Shorts
| Field | Rule |
|---|---|
| **Title** | Main keyword first (player/team), then the twist/emotion, 1–2 emoji. **User rule (Nov 16, 2026): always end the title with 3 hashtags, one of them `#shorts`** (e.g. `… #shorts #ronaldo #messi`). Keep the whole title ≤100 characters (YouTube's limit) and the words before the hashtags ≤60 so they read on a phone. |
| **Description** | Line 1 = one keyword-rich sentence (it shows in search). Then the story in 3–7 short lines (emoji bullets OK), then the question, then the parody/rights footer, then **3 hashtags** on the last line. The first 3 hashtags show above the title. Never more than 15 (YouTube ignores all hashtags if there are too many). |
| **Tags** | 10–15 comma-separated, ≤500 characters: player names (with and without accents: hojlund/højlund), match "A vs B", score "A 1-4 B", competition, the format phrase ("how it started how its going"), "football cartoon", "football animation", "soccer 365". Tags matter little for Shorts but help misspellings. |
| **Settings** | Category **Comedy** · Standard YouTube License · embedding on · not made for kids · altered/AI content: No · playlist "Soccer 365 Cartoons" · related video = previous episode. |
| **Pinned comment** | A numbered vote ("Comment 1–4 👇") or an easter-egg hunt. |

The Shorts feed (watch time, swipe-away rate) drives most views; metadata mainly helps search and suggested. So don't over-invest in tags; invest in the hook. **(consensus)**

## 2. TikTok
| Field | Rule |
|---|---|
| **Caption** | 100–300 characters works best for entertainment **(unsure: one source says 101–200 is the sweet spot)**. Structure: hook with keyword → 1-line story beat → question. Write the search phrase naturally ("Portugal lost 1-4 to Denmark") in the first 100 characters. |
| **Hashtags** | **3–5**, relevant and specific: 1–2 big (#football, #footballtiktok), 2–3 niche (#ronaldo, #nationsleague, #siuuu). No #fyp spam. **(consensus 3–5; unsure whether 1–2 is better)** |
| **On-screen text / cover** | The cover = frame 0 with the hook text. Keep the original sound (it's searchable). |
| **Pinned comment** | Easter egg or a "rate it 1–N" question. Reply to early comments with short, funny replies (a video reply to the best comment is a free second post). |
| **Timing** | Post while the topic is hot (within 24 h of the match). |

## 3. Instagram Reels
| Field | Rule |
|---|---|
| **Caption** | Only about **125 characters** show before "more". Line 1 = hook + keyword + the question. Then 2–4 short lines with the facts (emoji bullets), then the parody footer. Hard limit 2,200. **(consensus)** |
| **Keywords** | Put the main keyword in the first 2 sentences; IG search reads caption text. **(consensus)** |
| **Hashtags** | **3–5** relevant ones at the end. Old "30 hashtags" advice is outdated; some sources say more than 5 is suppressed **(unsure, but 3–5 is safe)**. |
| **Settings** | Cover = frame 0, cropped so the grid's 1:1/4:5 preview still shows the scoreboard/hook. Share to Feed on. Name the original audio ("<Title> – Soccer 365 (original)"). Add alt text with the keywords if offered. |
| **Pinned comment** | A numbered question (best shot 1–4, best reaction 1–4). |

## 4. Facebook Reels
| Field | Rule |
|---|---|
| **Caption** | Short: about 50–150 characters visible before "See more". Lead with the story ("How it started… How it's going…"), then a **genuine** open question ("Was it just a bad night, or do they really miss him?"). **(consensus)** |
| **Engagement bait: never** | Meta demotes posts that ask for reactions, comments, shares, tags or votes as bait: "Comment YES", "Like if…", "Tag a friend who…", "Share if…", "Vote with 😂/😮". "Watch till the end" is also bait unless the payoff is real. So on FB: **no YES/NO comment votes, no numbered votes, no tagging**. A real question is fine. **(consensus; this is Meta's long-standing policy)** |
| **Hashtags** | 0–2 (little effect on FB). |
| **Length** | The page's FB assistant said 45–60 s videos get +21.7% views (Ep2 data, `performance.csv`). Mention this when choosing a cut. |
| **Timing** | Within 24 h for match topics. |

## 5. X (Twitter)
| Field | Rule |
|---|---|
| **Main post** | **Native video upload, never a link** (links, including YouTube/TikTok links, get much less reach). ≤280 characters, counted with a script before shipping. Structure: hook line → 3–4 short lines of story (dates/scores) → one question. **(consensus)** |
| **Hashtags** | 0–2. They do little on X in 2026 **(consensus)**. |
| **Thread** | Reply 1 = the real facts + date + "cartoon parody". Reply 2 = an engagement question or the easter egg. If a link is ever needed, put it in a reply, never in the main post. |
| **Data (Nov 17 2026)** | Our X account: 450 followers. Episode posts got **53–180 views** and ~1 like each (Ep12 180, Ep13 165, Ep14 56). The worst platform by far. Why: a small account posting a long list-style caption + video is ignored. A quote of a Fabrizio Romano post also got only 53 views because it was just "To late" with no take. |
| **X playbook v2** | (1) **Reply-first:** within minutes of big breaking news (Romano, ESPN FC, B/R Football, club accounts), reply with a 1-line funny take + our clip/GIF. Replies on viral posts are where small accounts get seen. (2) **Main post = 1 short line + video**, no list, no "Show more" (first line must be the whole joke). (3) **Polls** for the episode question (polls get votes from non-followers). (4) Post our episode only as a reaction to news that is trending that day. (5) Effort budget: X gets ~10% of time; YouTube/TikTok/IG first. |
| **Engagement** | Reply to early replies fast; X weighs early engagement velocity and conversations. Quote-post the video after 24 h with a fresh angle. **(consensus)** |

## 6. Templates (copy and fill in)
**YouTube title:** `<Keyword hook>?! <emoji> <short twist> #shorts #<player1> #<player2/team>`

**TikTok:** `<Hook = on-screen text> <emoji> <1-line story with names + score>. <Binary question> 👇` + `#<player> #<team> #<signature> #<competition> #football #footballtiktok`

**Instagram:** line 1 `<Hook> <emoji> <question> 👇` · lines 2–4 `📈/📉/⚽ facts` · `Spot the hidden 🐐 👀` · `Real results · cartoon parody` · 3–5 hashtags

**Facebook:** `How it started: …` / `How it's going: …` / `<genuine open question>` / `Real results · parody`

**X:** `<one-line joke> <emoji>` + video (no list, fits without "Show more") → Reply 1 = poll with the episode question · Reply 2 facts. Plus 2–3 reply-posts with the clip under that day's biggest football news.

## 7. Pre-ship checklist
- [ ] **Order (user, Nov 16):** write the posts ONLY after the user has signed off the video ("chốt video"). While iterating, send only the video + a short summary. Once it is signed off, write the 5 dossiers and paste all 5 posts in the chat reply (the files alone are not enough).
- [ ] First line has the hook + the main name/keyword, matching the on-screen hook
- [ ] Every number/date/name is in `facts.md`; invented parts are labelled parody
- [ ] YouTube: title fits on a phone, 3 hashtags in the description, tags ≤500 characters, Comedy category, standard license, embedding on
- [ ] TikTok/IG: 3–5 hashtags; IG line 1 is under about 125 characters
- [ ] Facebook: no bait wording (comment/like/tag/share/vote), only a genuine question
- [ ] X: ≤280 characters (counted), native video, ≤2 hashtags, two replies ready
- [ ] Each platform's pinned comment asks a different question from its caption
- [ ] Post within 24 h for match topics; reply to comments in the first hour

## Length: ONE cut for every platform, 30–45 s (user decision, Nov 17 2026)
- Every episode ships as **one 30–45 s video** used on YouTube, TikTok, Instagram, Facebook and X. No per-platform length cuts.
- Why: FB creator tips (+284% views at 30–45 s for this page) and IG/FB retention (51 s lost most viewers before the payoff). Ep2 at 22 s did well, but the user chose one shared length.
- **No subtitle files** (user, Nov 17): episodes are near-silent visual comedy, so SRT adds nothing. Ignore FB's "add captions" tip.
- Post 19:00–23:00 Vietnam time (FB: +83%). Ask for shares + follows in the caption.
