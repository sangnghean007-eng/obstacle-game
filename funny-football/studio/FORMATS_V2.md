# Format v2 (user chose Nov 17 2026: "1" = formats that win on content + speed, not drawing quality)
Why: hand-built canvas cartoons can't match the big animation channels; best result so far (Ep2) was short + real + one idea.
Rules: hook text on frame 0 · one idea · built from verified data · comment trigger built in (score / pick / ranking) · 30–45 s · English · vox2/fx2 sound, new music style each time · no crests/photos (club names + colours only).

## Formats (rotate; never the same twice in a row)
1. **Guess the player from his career** (clubs + years tiles, silhouette, 3-s timer, reveal). Easy → medium → hard. CTA "Your score? 0/3…3/3". Template: `toon2/quiz01/`.
2. **Stat race / who has more** (animated bars racing: e.g. UCL titles since Mbappé left: PSG 2 · Madrid 0). CTA "Did you expect that? 👇".
3. **Ranking reveal** (top 5 counted down, #1 hidden till the end; built-in debate). CTA "Who's missing? 👇".
4. **Then vs Now** (same player/club, 2 numbers, split screen, a punchline stamp).
5. **Post-match reaction (≤6 h after a big match)**: scoreline + 3 facts + one meme stamp. Speed beats polish.
6. **Higher or lower** (two players, guess who has more X; 4 rounds).
Cartoon story episodes (Ep16/Ep17 style) become at most 1 per week.
- **Quiz rule (user, Nov 17):** never reveal the answers in a quiz video or its captions/tags. End on "Write your answers 👇"; reveal in the pinned comment after ~24 h (or in a follow-up video).
- **Main line (user, Nov 17):** classic exciting matches told as exaggerated caricature cartoons (Ep18). Each one a different narrative device (Ep18 = live-match chronicle with a dressing-room power-up).
